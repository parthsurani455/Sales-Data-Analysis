# Sales Data Analysis

## Project Overview
This project analyzes sales data using Python and Pandas to understand business performance.

## Technologies Used
- Python
- Pandas
- Matplotlib
- CSV Dataset

## Key Features
- Total Sales Analysis
- Total Profit Analysis
- Total Orders
- Monthly Sales Analysis
- Product-wise Sales
- Region-wise Sales
- Sales Visualization

## Project Files
- analysis.py - Performs sales data analysis.
- sales_data.csv - Sample sales dataset.

## How to Run

Install libraries:

pip install pandas matplotlib

Run the project:

python analysis.py
